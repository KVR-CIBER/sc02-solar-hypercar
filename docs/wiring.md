## ESP32-S3 DevKitC-1 pin map

| ESP pin | Connects to | Note |
|---|---|---|
| **5V** | MT3608 OUT+ (set to **5.0 V** first!) | keeps the ESP running when the pack sags to ~2.7 V at launch |
| **GND** | common ground | |
| **3V3** | DRV5023 VCC, R3 10k pull-up | |
| **GPIO4** | MOSFET module PWM/SIG | 20 kHz, 10 bit. LOW = motors off |
| **GPIO5** | START button → GND | internal pull-up |
| **GPIO6** | DRV5023 OUT (+ R3 10k to 3V3) | 4 magnets in the front-left wheel → 31.4 mm per pulse |
| **GPIO1** | divider mid-point (R1 100k from BUS+, R2 47k to GND) | battery voltage, ADC |
| GPIO48 / 38 | on-board RGB LED | status colour (depends on board revision; `RGB_BUILTIN`) |

## Power path (high current, 20 AWG, keep short)

`4×AA (series, kit holders)` → `F1 10 A fuse` → `S1 toggle switch` → **BUS+** → `M1 ∥ M2 (+)`
`M1 ∥ M2 (−)` → `MOSFET module` → **GND** → `battery −`

Peak current ≈ 7 A for 0.3 s with launch control (8.4 A at full throttle from t = 0), then dropping to 3 A at the finish (simulation). A 10 A fuse doesn't blow on that, but it does blow on a short circuit (NiMH AA can push 15–20 A).

## Rules this wiring follows

| Rule | How |
|---|---|
| 4.2 panel must work as an energy source | panel → D1 → BUS+, so it charges/feeds the bus whenever it's lit |
| 4.3 diode against back-feed into the panel | D1 1N5819 Schottky (0.3 V drop) |
| 4.5 panel not modified | only its leads are used, it lies loose in the frame |
| 5.1 no other energy storage | C1 (470 µF) is a decoupling capacitor (0.006 J). **If a judge doubts it, leave C1 out**: the MT3608 and MOSFET module have their own small capacitors |
| 5.5 cells not soldered | kit holders, wires soldered to the holder tabs only |
| 5.6 cells in series | 2 holders × 2 cells in series = 4.8 V |
| 5.7 fuse recommended | F1 10 A, specify it in the design report |
